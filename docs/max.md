# Graphy в MAX

Graphy работает как сервис внутри MAX: бот присылает кнопку входа, приложение открывается в WebView, пользователь выбирает роль «Ученик» или «Учитель».

Рабочий бот: <https://max.ru/ideya_fiks_2_bot>

## Как это устроено

1. Пользователь пишет боту `/start`. Если он в списке доступа, бот отвечает кнопкой «Открыть Graphy» со ссылкой входа.
2. Ссылка содержит подписанный токен: она не истекает и открывается любое число раз, в том числе на другом устройстве. Если приложение запущено как мини-приложение MAX, вход идёт по подписанным данным `WebApp.initData`.
3. Хаб (`scripts/max-hub.mjs`) проверяет подпись, создаёт пользователя, выдаёт сессию на 7 дней и запускает ему отдельного агента.
4. Учитель создаёт класс и отправляет ученикам ссылку-приглашение; ученик присоединяется по ней.

Если адрес мини-приложения не зарегистрирован в кабинете MAX, приложение всё равно работает по ссылкам от бота.

## Переменные окружения

Шаблон: [.env.example](../.env.example).

| Переменная | Назначение |
|---|---|
| `MAX_BOT_TOKEN` | токен бота; наличие включает режим хаба |
| `GRAPHY_PUBLIC_URL` | публичный HTTPS-адрес сервиса, попадает в ссылки входа |
| `MAX_ADMIN_CLAIM` | одноразовый код: отправьте боту `/claim <код>`, чтобы стать администратором |
| `MAX_ADMIN_IDS` | список id администраторов через запятую (альтернатива `/claim`) |
| `GRAPHY_LLM_KEY`, `GRAPHY_LLM_UPSTREAM` | ключ и адрес провайдера моделей (по умолчанию OpenRouter); пользователи его не видят |
| `GRAPHY_MAX_AGENTS` | сколько агентов держать в памяти одновременно (по умолчанию 3 для сервера на 1 ГБ) |
| `GRAPHY_DAILY_LLM_REQUESTS` | лимит запросов к модели на пользователя в сутки |
| `GRAPHY_LOG_PROMPTS` | `1`: по умолчанию писать в `llm.log` текст сообщений учеников и анонимных токенов (до 600 символов, ключи и токены скрываются). Переключается командой `/prompts on` и `/prompts off`, значение хранится в `hub.json` |
| `GRAPHY_NEW_USER_DAILY` | запросов в сутки для пользователей, зарегистрированных после первого запуска этой версии (по умолчанию 40); меняется `/setlimit new <число>` |
| `GRAPHY_REPORTS_PER_HOUR`, `GRAPHY_AUTO_BLOCK_HIGH` | сколько сообщений от ИИ-агента в час принимать от одного пользователя (6) и после скольких сообщений высокой важности за час блокировать автоматически (0 = не блокировать) |
| `GRAPHY_USER_DISK_MB`, `GRAPHY_SANDBOX_LISTENER_GRACE_MS` | порог занятого места на пользователя для алерта (1000 МБ) и сколько секунд процесс пользователя может держать открытый порт до остановки (45 с) |
| `GRAPHY_TRUSTED_PROXIES` | адреса, которым верим в `X-Forwarded-For` (по умолчанию в контейнере только шлюз docker-сети x.x.x.1) |
| `GRAPHY_DAILY_LLM_TOTAL` | общий суточный потолок запросов для всех залогиненных пользователей вместе (по умолчанию 6000) |
| `GRAPHY_LLM_PER_MIN` | запросов в минуту на пользователя, скользящее окно (по умолчанию 40) |
| `GRAPHY_LLM_IP_PER_MIN` | запросов в минуту на IP-адрес (по умолчанию 120). Адреса 127.x не считаются: так обращаются агенты внутри контейнера |
| `GRAPHY_ACTIVE_ALERT_REQUESTS`, `GRAPHY_ACTIVE_ALERT_MINUTES` | алерт админам, когда пользователь сделал столько запросов за окно (по умолчанию 100 за 15 минут) |
| `GRAPHY_SUSPICIOUS_AUTH_FAILS`, `_ANON_TOKENS`, `_LIMIT_HITS`, `_BLOCKED_HITS`, `_CLAIM_FAILS` | пороги алертов о подозрительной активности (10 / 8 / 5 / 5 / 3 по умолчанию), см. ниже |
| `GRAPHY_PUBLIC_LLM` | `off` выключает публичный уровень сервиса Graphy для локальных установок |
| `GRAPHY_ANON_USD_TOKEN`, `_IP`, `_TOTAL` | суточные лимиты публичного уровня по оценке стоимости, USD (1 / 2.5 / 12 по умолчанию) |
| `SEARXNG_URL`, `GRAPHY_STT_URL` | адреса поиска и распознавания речи, если они подняты |

## Команды администратора бота

`/users` (список доступа), `/adduser <id>`, `/open` и `/close` (открыть доступ всем или только по списку), `/claim <код>`. Незнакомые пользователи попадают в список ожидания, их id администратор видит в `/users`.

Модели и нагрузка (только для админов, `/help` показывает список):

- `/stats`: сводка за сутки: запросы, отказы 429, ошибки 4xx/5xx, расход анонимного режима в USD, статус паузы, топ-10 пользователей;
- `/top`: топ-20 пользователей и топ-10 IP;
- `/log <id|токен|IP> [N]`: последние запросы (до 50) MAX-пользователя по id, анонимного токена по короткому id (8 символов) или IP: время по Москве, путь, статус, длительность, размер. Если включён текст запросов (`/prompts on`), под строкой выводится сообщение ученика;
- `/reports [id]`: последние сообщения ИИ-агента админу (инструмент `report_to_admin`): кого и за что он заметил, с цитатой запроса. Каждое такое сообщение сразу приходит в MAX с важностью и подсказками `/log`, `/block`, `/setlimit`;
- `/prompts on|off`: писать ли текст запросов в лог. Это сообщения детей и школьников: включайте осознанно, предупредите пользователей в политике конфиденциальности и не давайте доступ к логу посторонним;
- `/who <id>`: профиль, статус и расход пользователя; `/ip <адрес>`: расход IP;
- `/block <id>` и `/unblock <id>`: закрыть и вернуть доступ (администратора заблокировать нельзя), заблокированный получает 403 на запросы к моделям;
- `/limits`: текущие значения лимитов;
- `/setlimit <id> <запросов в сутки> [в минуту]`: индивидуальный лимит пользователя, действует сразу и хранится в `hub.json`; `/setlimit <id> сброс` возвращает общий. Админов лимиты не касаются. Текущие индивидуальные лимиты видны в `/limits`, а у конкретного пользователя в `/who <id>`;
- `/llmoff` и `/llmon`: аварийная пауза моделей для всех, кроме админов (503), флаг сохраняется между перезапусками.

Сутки считаются по UTC и сбрасываются в 03:00 по Москве. Админы вне лимитов и вне паузы; запросы со своим ключом OpenRouter не лимитируются и не ставятся на паузу, потому что идут не через ключ сервиса.

Каждый запрос к `/llm` пишется строкой JSON в `llm.log` (время, kind `user|anon|own`, id, IP, путь, статус, мс, размер тела, модель; токены и ключи не пишутся, у анонимных только 8 первых символов id; текст сообщений только при `/prompts on`). При 5 МБ файл переименовывается в `llm.log.1`. Статистика суток лежит в `llm-stats.json` и восстанавливается после перезапуска в тот же день.

Подозрительная активность тоже приходит админам сообщением в MAX (не чаще раза в час на событие):

- с одного IP за 10 минут много неверных данных входа: подделанные токены `/llm`, ссылки входа и данные MAX (подбор);
- неверный код `/claim` три раза за час (подбор кода администратора);
- с одного IP за час много разных анонимных токенов (обход лимита на токен);
- пользователь или IP снова и снова упирается в лимиты запросов;
- заблокированный пользователь продолжает слать запросы к моделям.

Адреса `127.x` в этих проверках не участвуют: так обращаются агенты внутри контейнера.

Остальные алерты (не чаще раза в час на событие): пользователь достиг 80% и 100% суточного лимита, сработал лимит в минуту, общий расход дошёл до 50/80/100%, кто-то начал активно пользоваться агентом.

## Развёртывание на сервере

Требования: Docker, домен или `sslip.io`-адрес с HTTPS (MAX открывает приложения только по HTTPS), 1 ГБ ОЗУ с запасом swap.

```bash
docker network create graphy-net
# поиск и распознавание речи — по желанию
docker run -d --name searxng --network graphy-net -v $PWD/searxng/settings.yml:/etc/searxng/settings.yml:ro searxng/searxng:latest
docker run -d --name graphy-hub --restart unless-stopped --network graphy-net --env-file .env \
  -e SEARXNG_URL=http://searxng:8080 -e GRAPHY_PUBLIC_URL=https://your.domain \
  -p 127.0.0.1:5174:5174 -v graphy-data:/data -v graphy-workspace:/workspace \
  --user 0:0 --cap-drop ALL --cap-add CHOWN --cap-add SETUID --cap-add SETGID --cap-add FOWNER --cap-add DAC_OVERRIDE --cap-add KILL \
  --security-opt no-new-privileges:true --pids-limit 256 --memory 640m \
  --read-only --tmpfs /tmp:rw,exec,nosuid,size=256m graphy:latest
```

Хаб запускается от root внутри контейнера, чтобы переключать uid агентов; поэтому остальные права ограничены. Право `KILL` обязательно: без него root не может завершать агентов, работающих под другими uid, остановленные агенты остаются жить и держат порты, а вход зависает с ошибкой `Address already in use`. При старте без этого права хаб пишет в лог `WARNING: CAP_KILL is missing`. Перед ним ставится обратный прокси с TLS, проксирующий на `127.0.0.1:5174` (пример для Caddy: `your.domain { reverse_proxy 127.0.0.1:5174 }`).

Обновление: собрать или загрузить новый образ, `docker rm -f graphy-hub`, запустить заново. Данные в томах сохраняются; простой около минуты.

Хаб можно поднять локально с тестовым токеном и проверить школу в обычном браузере: см. [scripts/e2e-school/README.md](../scripts/e2e-school/README.md). Это не заменяет проверку в настоящем MAX WebView.
