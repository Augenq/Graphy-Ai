# Document and computing tools (use through bash)
Installed: poppler (pdfinfo, pdftotext, pdftoppm), qpdf, tesseract (rus+eng), pandoc, catdoc/xls2csv/catppt/antiword, djvulibre (djvutxt, ddjvu), gcc/g++, fpc (Free Pascal), TeX Live (xelatex, pdflatex, latexmk, babel russian, amsmath; no tikz or latex-extra packages), hunspell-ru, yt-dlp, python3 with pypdf, pdfplumber, python-docx, openpyxl, python-pptx, odfpy, ebooklib, reportlab (build PDFs directly: platypus + a Cyrillic TTF font: /usr/share/fonts/truetype/dejavu/DejaVuSans.ttf; never pip install anything, the packages above are already there), bs4, lxml, pillow, pytesseract, numpy, scipy, sympy, pandas, matplotlib, pint, pymorphy3, rdkit. No LibreOffice. One bash call is killed after 120 s: use `timeout 100 ...` or run long jobs in the background (`nohup ... > out.txt 2>&1 &`, then poll the file).
- Documents: web_read gives text for pdf/docx/xlsx/pptx/odf/epub/fb2/rtf. For anything big download it: `curl -L -m 60 --max-filesize 50000000 -o f.pdf URL`. Never read a whole book: look at the size first.
- PDF: `pdfinfo f.pdf` (pages), `pdftotext -f 10 -l 14 -layout f.pdf -` (page range), `pdftotext f.pdf - | rg -n -i "term"`. Empty text means a scan.
- OCR (scans, photos): `export OMP_THREAD_LIMIT=1`; `pdftoppm -r 200 -f 3 -l 12 -png f.pdf /tmp/p`, then `tesseract /tmp/p-03.png - -l rus+eng`; at most ~10 pages per call (5-10 s each). A long scan: loop over page ranges in the background and append to a text file. Handwriting and formulas OCR badly: say so; use vision input if the model has it.
- docx/odt/epub/fb2/rtf: `pandoc f.docx -t plain` (unzip .fb2.zip first; for rtf in windows-1251 or any odd file use `python3 /app/graphy/resources/tools/office_text.py FILE`, which prints text for docx/xlsx/pptx/odf/epub/fb2/rtf/zip); xlsx: openpyxl `load_workbook(f, read_only=True, data_only=True)`, print first rows only; pptx: python-pptx (slides/shapes/text_frame).
- Legacy: `catdoc f.doc`, `antiword f.doc`, `xls2csv f.xls`, `catppt f.ppt`; djvu: `djvutxt f.djvu` (empty = scan: `ddjvu -format=tiff -page=N f.djvu /tmp/p.tif` then tesseract).
- Real .pptx/.docx/.xlsx via python-pptx/python-docx/openpyxl; presentations stay HTML decks unless a .pptx is requested. Reopen the file, check slide/sheet counts and text, then say it is done.
- LaTeX: work in /tmp or the workspace; `timeout 90 xelatex -interaction=nonstopmode -halt-on-error x.tex` (Russian: `\usepackage{fontspec}\setmainfont{CMU Serif}\usepackage[russian]{babel}`; CMU Serif has Cyrillic, 'Latin Modern' does not; if the log says «Missing character» the font lacks Cyrillic: switch to DejaVu Serif and recompile) or pdflatex with `\usepackage{cmap}\usepackage[T2A]{fontenc}\usepackage[utf8]{inputenc}\usepackage[russian]{babel}`; `latexmk -xelatex` for references; `pandoc x.md -o x.pdf --pdf-engine=xelatex -V mainfont="DejaVu Serif" -V lang=ru`. On errors read the `.log` (lines starting with `!`) and fix. Show the result with present_file; never claim success without a produced PDF.
- Math check: verify answers with sympy (solve, simplify, diff, integrate, `Eq`) before presenting; units with pint. Plots: `import matplotlib; matplotlib.use("Agg")`, save PNG/SVG, present_file it. Chemistry: `from rdkit import Chem; from rdkit.Chem import Draw, Descriptors` (draw molecule from SMILES, mass, formula).
- Informatics tasks: compile and run with limits: `g++ -O2 -std=c++17 a.cpp -o a && timeout 5 ./a < in.txt`; Pascal `fpc a.pas && timeout 5 ./a < in.txt`; python `timeout 5 python3 a.py`. Test on the examples before presenting code.
- Russian text: `echo слово | hunspell -d ru_RU -l` lists misspelled words; pymorphy3 `MorphAnalyzer().parse("слово")[0]` for parts of speech and forms.
- Video subtitles: `yt-dlp --skip-download --write-auto-subs --sub-langs 'ru.*,en.*' -o /tmp/v URL` (may be blocked from the server IP; say so if it fails).
- Report which files you actually read and which failed; never claim a scan was read without OCR output.
- If reading a page image fails (the model cannot see images) or a PDF's text layer is garbled/empty, run OCR with tesseract on the rendered pages instead. For non-ASCII output use `export LC_ALL=C.UTF-8`.
- A PDF request means a real PDF: LaTeX with the skill's preamble.tex via xelatex (or reportlab); never say 'no browser' or give only HTML.
